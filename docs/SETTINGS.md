# 统一设置（main 开发版）

此页对应当前 main 源码的新设置界面，尚未包含在 v0.2.0 Release APK 中。安装已发布版本的用户仍会看到旧入口；可自行构建 main，或等待后续正式安装包。

右下角只保留「全部应用」「其他信号源」「设置」。壁纸统一在「设置 → 背景」中管理。

## 操作逻辑

设置按分组展开，左侧为选项，右侧复用真实首页布局作为预览。方向键只移动焦点，按确定才保存。勾选标记是当前已应用值，高亮底板是遥控器焦点。无需另点保存；返回逐层退出，并保留已经确认的修改。

壁纸是例外：移动焦点会临时预览候选照片，但不保存、不改变真实首页。按确定才应用；返回取消候选预览和仍未完成的加载，保留最后一次应用的图片。加载或保存失败会提示，并保留已有设置。

## 分组

| 分组 | 可设置内容 |
| --- | --- |
| 背景 | 照片、浅色、深色；照片模式下进入壁纸和轮播 |
| 布局 | 纵向列表、横向 Dock；应用和右侧操作分别选择文字、图标、图标＋文字 |
| 字体 | 轻盈、标准、衬线；列表字号小、标准、大 |
| 选中样式 | 文字高亮、半透明底板；底板柔和、浓雾、清透；未选中项淡化程度 |
| 首页内容 | 1–9 个入口；添加、上移、下移、从首页隐藏；本次编辑内可撤销 |
| 电视与启动 | 原有开机自动进入开关、电视系统设置、小米原桌面 |

## 壁纸与轮播

- 「设置 → 背景 → 壁纸」浏览并选择打包的照片。
- 「设置 → 背景 → 轮播」选择固定，或每 1 / 5 / 15 / 30 分钟。
- 选照片与选择轮播模式相互独立。要固定一张照片，选择照片后把轮播设为固定。
- 默认依然是每 5 分钟轮播。升级会保留原来固定/轮播模式、已选照片和间隔。
- 轮播仅在照片首页显示时计时；设置页、全部应用、外部 App、纯色背景会暂停，回到首页重新开始间隔。
- 当前没有联网图库或电视端文件导入；自带照片或构建时打包的图片均可使用。

## 布局与图标

列表上下选择应用，向右进入操作区；Dock 左右滚动，向上进入操作区，也可从最右项向右进入。右侧操作按上下移动，向左回到上次应用。列表和 Dock 共用相同首页顺序。

图标模式使用已安装应用的图标。PS5、Apple TV 信号源和右侧操作使用本项目绘制的图形。仅图标时，聚焦项会显示名称。这里没有任意上传/更换图标的功能。

## 字体与焦点

字体来自电视的 Android 系统；具体字形取决于固件，中文由系统回退。没有附带 CleanFrame 私人版付费字体。字体风格用于首页名称、操作区和时钟，设置页保持系统字体。字号选项用于纵向列表，Dock 使用适合卡片的固定字号。

半透明底板用颜色、透明度和细边框表现层次，没有实时背景模糊，也不是对 CleanFrame 预渲染材质的完整移植。

## 首页内容

从「首页内容」选择一个入口，可上移、下移或隐藏。隐藏只从本桌面移除，不卸载电视上的应用。「添加入口」包含可启动应用，以及被移除的默认信号源入口。

首页至少一项，最多九项。列表和 Dock 超出可见区域时随遥控器焦点滚动。「撤销上一步」撤销本次打开设置后的编辑；退出设置后清空撤销历史，已保存顺序保留。

首次升级保持原六个入口；此后使用本地保存的顺序。PS5 / Apple TV 是默认名称，不代表自动识别硬件；端口和机型适配仍遵循 XiaomiControls。

## 与 CleanFrame 的关系

参考其[设置交互说明](https://github.com/nthnclrk/CleanFrame/blob/fa537d1892b71d2de2bf94c24cbff3812e9f70d5/docs/interaction-behaviour.md)的分组、预览、确认应用和返回层级，在原生 Android 控件中重新实现。没有复制 Tizen 运行代码、Samsung Art Mode、付费字体或上游照片。

此设置更新没有修改公共版的开机策略、Home 角色、系统启动目标或权限。私人电视已经验证的待机修复仍单独保留；不能据此认为公开 v0.2.0 包已经支持待机自动进入。
